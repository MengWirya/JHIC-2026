Rekayasa Perangkat Lunak

Mempelajari seluruh aspek produksi software
seperti aplikasi web dan aplikasi mobile.

Siswa nantinya akan belajar dan dituntut untuk bisa membuat aplikasi berbasis web dengan teknologi pemrograman sesuai standar industri. Back-end menggunakan Node JS/Laravel, dan Front-end menggunakan React JS/Vue JS.
Siswa nantinya akan belajar dan dituntut untuk bisa membuat aplikasi berbasis mobile dengan teknologi pemrograman sesuai standar industri. Bahasa pemrograman yang dipelajari meliputi Java, Kotlin, Swift (iOS), React Native, dan Flutter.
Lulusan RPL banyak bekerja pada posisi mobile developer, web developer, database engineer, system analyst, UI/UX designer, freelancer/kerja remote, dan berwirausaha dibidang IT.

Teknik Komputer dan Jaringan

Mempelajari cara merakit, instalasi, dan perbaikan komputer,
instalasi jaringan Local Area Network (LAN) dan Wide Area Network (WAN), serta internet of things (IoT).

Aktivitas yang dilakukan sistem atau seseorang dalam rangka melindungi sistem komputer dari serangan. Biasanya serangan tersebut bersifat ilegal.
Lulusan TKJ banyak bekerja pada posisi network designer, network engineer, network operating center (NOC), DevOps, dan berwirausaha dibidang IT.

Pengembangan Gim

Mempelajari seluruh aspek pengembangan gim
seperti desain, pengembangan, dan perilisan game.

Lulusan Pengembagan Gim banyak bekerja pada posisi game developer, game designer, game artist, game audio engineer, game producer, quality assurance tester, freelancer/kerja remote, dan berwirausaha dibidang IT.
