# TODO 03 - Public Content And Landing

## Tujuan
Melengkapi halaman publik yang dijanjikan di pitch deck menggunakan data Prisma native.

## Pekerjaan
- Hubungkan landing page ke data PRESTASI terbaru.
- Tambahkan showcase mitra industri dan testimoni alumni.
- Tambahkan section produk unggulan BLUD.
- Tambahkan halaman atau section Galeri.
- Tambahkan halaman Agenda bila disepakati sebagai scope final.
- Lengkapi Profil & Prestasi: visi, misi, akreditasi, dan daftar prestasi.
- Pastikan semua link navigasi tidak mengarah ke route legacy yang sudah dihapus.

## API atau credential
Tidak ada API eksternal. Data dibaca dari Prisma dengan status `PUBLISHED`.

## Selesai jika
- Tidak ada halaman publik prioritas yang menampilkan data hard-coded sebagai data final.
- Draft tidak tampil ke pengunjung.
- Semua halaman responsive pada desktop, tablet, dan mobile.
- Tidak ada import atau filesystem read terhadap `reference/`.
